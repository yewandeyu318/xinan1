# S-DES 加解密系统 —— 开发手册

本手册面向开发者与代码审查者：说明系统架构、模块划分、**核心库接口文档**、关键实现约定与扩展方法。

---

## 1. 系统架构

```text
                    ┌─────────────────────────────┐
                    │        src/SDES.h/.cpp       │   ← 唯一的算法核心（小组统一）
                    │  置换表常量 + 加解密 + 破解    │
                    └──────────────┬──────────────┘
                                   │ 全部上层程序共用，保证交叉测试一致
        ┌───────────────┬──────────┴──────────┬───────────────┐
        ▼               ▼                     ▼               ▼
  Main.cpp         SdesGui.cpp        TcpServerMain.cpp  TcpClientMain.cpp
  控制台程序        Win32 GUI           TCP 服务端          TCP 客户端
 （第1~5关）      （第1/3/4/5关）      （接收密文解密回显）  （加密发送）
```

设计原则：**算法与界面彻底分离**。任何一层（控制台/GUI/TCP）都只调用 `SDES` 命名空间下的接口，不重复实现算法；置换表集中在 `SDES.h` 顶部常量区，课程 PPT 若有出入只改一处。

## 2. 核心库接口文档（SDES.h）

### 2.1 常量表

| 常量 | 规格 | 说明 |
|---|---|---|
| `P10Table[10]` | 10bit → 10bit | 密钥初始置换 P10 |
| `P8Table[8]` | 10bit → 8bit | 密钥压缩置换 P8（生成子密钥） |
| `IPTable[8]` | 8bit → 8bit | 明文初始置换 IP |
| `IPInverseTable[8]` | 8bit → 8bit | 逆初始置换 IP⁻¹ |
| `EPTable[8]` | 4bit → 8bit | 扩展置换 E/P |
| `P4Table[4]` | 4bit → 4bit | S 盒后置换 P4 |
| `S0Box[4][4]` / `S1Box[4][4]` | 4bit → 2bit | 两个 S 盒（行=b0b3，列=b1b2） |

**比特编号约定**：置换表中的数字是"输入比特编号"，从 1 开始，1 表示输入有效位宽的最高位。例如 IP 表首元素 2 表示输出的第 1 位取输入 8bit 的第 2 位。

### 2.2 函数接口

```cpp
void GenerateSubKeys(uint16_t KeyBit10, uint8_t& Key1Out, uint8_t& Key2Out);
```
由 10bit 主密钥生成两个 8bit 子密钥。流程：P10 → 循环左移 1 位 → P8 得 K1；再左移 2 位 → P8 得 K2。
示例：`GenerateSubKeys(0b1010000010, k1, k2)` → k1=`0xA4`(10100100)，k2=`0x43`(01000011)。

```cpp
uint8_t EncryptBit8(uint8_t PlainBit8, uint16_t KeyBit10);
```
核心加密：IP → fK(K1) → SW → fK(K2) → IP⁻¹。
示例：`EncryptBit8(0x97, 0x28A)` → `0x38`（即 10010111 + 1010000010 → 00111000，教材算例）。

```cpp
uint8_t DecryptBit8(uint8_t CipherBit8, uint16_t KeyBit10);
```
解密：与加密同结构，仅子密钥顺序颠倒（先 K2 后 K1）。满足 `DecryptBit8(EncryptBit8(P,K),K) == P`。

```cpp
std::string EncryptString(const std::string& PlainText, uint16_t KeyBit10);
```
字符串加密：按 1 Byte 分组逐字节加密，返回**大写十六进制密文串**。ASCII 直接处理；中文按其编码字节流（UTF-8 下每汉字 3 字节）逐字节加密，天然支持 Unicode。

```cpp
std::string DecryptHexString(const std::string& HexCipherText, uint16_t KeyBit10);
```
十六进制密文解密，还原原字符串；密文格式非法（奇数长度或含非 hex 字符）时返回空串。

```cpp
std::vector<uint8_t> EncryptBytes(const std::vector<uint8_t>& PlainBytes, uint16_t KeyBit10);
std::vector<uint8_t> DecryptBytes(const std::vector<uint8_t>& CipherBytes, uint16_t KeyBit10);
```
原始字节序列的逐字节加解密，供 TCP 等需要二进制流的场合。

```cpp
std::vector<uint16_t> BruteForceKeys(uint8_t PlainBit8, uint8_t CipherBit8);
```
遍历 1024 个密钥，返回所有满足 `Encrypt(P,K)==C` 的密钥（升序）。核心库为单线程确定性实现；控制台程序在第4关用 `std::thread` 对其做了多线程并行包装（见 4.2）。

```cpp
std::vector<uint16_t> FindAllKeys(uint8_t PlainBit8, uint8_t CipherBit8, int& KeyCountOut);
```
封闭性分析：同源逻辑，额外输出满足密钥个数，用于第5关"明密文对不唯一确定密钥"的定量分析。

```cpp
std::string ToBitString8(uint8_t Value);      // 数值 → "10010111"
std::string ToBitString10(uint16_t Value);    // 数值 → 10 位二进制串
bool ParseBitString(const std::string& BitString, uint32_t& ValueOut); // 解析 0/1 串，非法返回 false
```

## 3. 关键实现约定

1. **通用置换函数** `Permute(Value, Table, TableLen, InputWidth)`：所有 P 盒复用同一实现，`InputWidth` 用于区分"P8 表输入 10bit"这类表长 ≠ 输入位宽的情况。
2. **S 盒行列**：输入 4bit 记为 b0b1b2b3（b0 为最高位），行号 = b0b3，列号 = b1b2，输出为表中的 2bit 值。
3. **循环左移**：`LeftShift10` 对 10bit 值的高低各 5bit 分别循环左移指定位数。
4. **错误处理约定**：输入解析失败返回 false / 空串，不抛异常；GUI 层弹窗提示，控制台层打印错误。

## 4. 上层程序实现要点

### 4.1 控制台（Main.cpp）
- Windows 下通过 `SetConsoleOutputCP(CP_UTF8)` 保证中文输出；
- 菜单编号与课程五关一一对应（[1]~[5]），[6][7] 为配套工具。

### 4.2 多线程暴力破解（第4关）
```cpp
unsigned ThreadCount = std::thread::hardware_concurrency();  // 实测机器为 16
```
- N 个线程按 `TryKey = 线程Id, Id+N, Id+2N, ...` 交错扫描整个 1024 密钥空间，互斥锁保护结果表；
- 计时使用 `std::chrono::steady_clock`，同时用 `system_clock` 打印毫秒级墙钟时间戳；
- 每完成 256 个密钥输出一次进度（带耗时），便于录屏展示；线程结束后对结果 `std::sort` 保证输出确定性。

### 4.3 GUI（SdesGui.cpp）
- 纯 Win32 API（CreateWindow + 消息循环），无第三方库；控件 ID 以 `IDC_` 前缀宏定义；
- 宽字符（UTF-16）与 UTF-8 之间通过 `WideCharToMultiByte / MultiByteToWideChar` 转换后调用核心库。

### 4.4 TCP（TcpServerMain.cpp / TcpClientMain.cpp）
- Winsock2，报文为两行文本：第 1 行 10bit 密钥，第 2 行十六进制密文，`\n` 结尾；
- 服务端解密后回传 `OK: <明文>\n`；密钥非法回传 `ERROR: invalid key\n`；
- 字符串按 UTF-8 字节流传输，两端无需额外编码转换。

## 5. 编译与构建

| 目标 | 命令 |
|---|---|
| 控制台 | `g++ -std=c++17 -O2 -o SdesConsole.exe src/SDES.cpp src/Main.cpp -pthread` |
| GUI | `g++ -std=c++17 -O2 -municode -mwindows -o SdesGui.exe src/SdesGui.cpp src/SDES.cpp` |
| TCP 服务端 | `g++ -std=c++17 -O2 -o SdesServer.exe src/TcpServerMain.cpp src/SDES.cpp -lws2_32` |
| TCP 客户端 | `g++ -std=c++17 -O2 -o SdesClient.exe src/TcpClientMain.cpp src/SDES.cpp -lws2_32` |

验证工具：`tools/sdes_reference.py`（独立 Python 参考实现，用于全量交叉验证）；`tools/gen_media.py`（将真实运行输出渲染为报告用截图与动图，依赖 Pillow）。

## 6. 代码规范落实

- **命名**：类/函数/全局常量大驼峰（`EncryptBit8`、`CrossTestSamples`），局部变量小驼峰（`PlainValue`、`FoundKeys`），见名知意；
- **注释**：每个文件有文件头注释（用途、编译命令），每个接口有参数/返回值/示例注释，每个算法步骤有行内注释；
- **消灭繁复逻辑**：置换统一走 `Permute`，加解密共用 `FunctionFk`/`SwitchSW`，暴力破解与封闭性分析复用同一遍历逻辑；
- **无全局可变状态**：核心库全部为无副作用的纯函数，线程安全（多线程破解中仅结果容器使用互斥锁）。

## 7. 扩展指南

| 想做什么 | 改哪里 |
|---|---|
| 更换 S 盒 / 置换表（对齐 PPT） | `src/SDES.h` 顶部常量区，改完重跑菜单 [2] 交叉测试确认 |
| 增加新的界面功能 | 在 `SdesGui.cpp` 增加控件 ID 与按钮响应，调用 `SDES` 命名空间接口即可 |
| 支持任意分组长度 | 需重新设计 `Permute` 位宽约定；当前实现固定 8bit 分组（S-DES 定义如此） |
| 跨平台移植 | GUI 与 TCP 依赖 Win32/Winsock；Linux 下将 winsock2 替换为 POSIX socket，GUI 可改 Qt |
