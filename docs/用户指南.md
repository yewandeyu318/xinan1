# S-DES 加解密系统 —— 用户指南

本指南面向课程演示与验收：教你从零编译、启动并使用系统的全部功能。程序共四个入口（控制台 / 图形界面 / TCP 服务端 / TCP 客户端），全部共用同一套 S-DES 核心算法。

---

## 1. 环境准备

- 操作系统：Windows 10/11（GUI 与 TCP 使用 Win32 API）
- 编译器：MinGW-w64 的 g++（任意 9 以上版本均可），或 MSYS2
- 无任何第三方库依赖

## 2. 编译（三条命令）

在项目根目录 `SDES/` 下执行：

```bash
# ① 控制台程序（第1~5关全部功能）
g++ -std=c++17 -O2 -o SdesConsole.exe src/SDES.cpp src/Main.cpp -pthread

# ② 图形界面程序
g++ -std=c++17 -O2 -municode -mwindows -o SdesGui.exe src/SdesGui.cpp src/SDES.cpp

# ③ TCP 服务端与客户端
g++ -std=c++17 -O2 -o SdesServer.exe src/TcpServerMain.cpp src/SDES.cpp -lws2_32
g++ -std=c++17 -O2 -o SdesClient.exe src/TcpClientMain.cpp src/SDES.cpp -lws2_32
```

> `build/` 目录内已有编译好的四个 exe，可直接使用。

## 3. 控制台程序（SdesConsole.exe）

双击或在终端运行，出现主菜单：

```text
[1] 第1关：8bit 明文加解密
[2] 第2关：交叉测试（统一明密文样本）
[3] 第3关：字符串加密（ASCII / 中文）
[4] 第4关：暴力破解（多线程 + 计时）
[5] 第5关：封闭性分析（多密钥）
[6] 字符串解密（十六进制密文）
[7] 全量封闭性扫描（报告数据）
[0] 退出
```

### 3.1 第1关：8bit 加解密

输入 `1` → 按提示输入 8 位二进制明文（如 `10101010`）和 10 位二进制密钥（如 `1010000010`）。
程序输出子密钥 K1/K2、8bit 密文，并自动用密文做解密回环验证。

### 3.2 第2关：交叉测试

输入 `2`，程序自动运行 10 组小组统一样本，逐条输出密文与解密回环结果，全部显示"通过"即说明算法流程一致。

### 3.3 第3关：字符串加密 / 解密

- 加密：输入 `3` → 输入任意字符串（支持英文、中文、数字混合）→ 输入 10bit 密钥 → 得到十六进制密文，并附解密回环验证。
- 解密：输入 `6` → 输入十六进制密文 → 输入同一密钥 → 还原明文。

### 3.4 第4关：暴力破解（带时间戳计时）

输入 `4` → 输入 8bit 明文与 8bit 密文。程序以多线程并行遍历 1024 个密钥，实时打印时间戳与进度，最后输出**总耗时**和全部满足条件的密钥。本环节适合录屏/截图，动图演示见 `docs/暴力破解动图.gif`。

### 3.5 第5关：封闭性分析

输入 `5` → 输入明密文对，程序列出所有能将该明文加密为该密文的密钥及数量。
输入 `7` 可对全部 65536 个明密文对做全量扫描，输出"满足密钥个数分布直方图"（用于第5关报告分析）。

## 4. 图形界面（SdesGui.exe）

窗口分三个分组，全部按钮操作：

| 分组 | 操作 |
|---|---|
| 第1关：8bit 数据加解密 | 填明文、密钥 → 点"加密"看密文 → 点"解密回环"还原 |
| 字符串加解密 | 填明文字符串 → 点"加密字符串"得十六进制密文；反向点"解密密文"还原 |
| 第4关/第5关：暴力破解与封闭性分析 | 填明密文对 → 点"遍历 1024 密钥查找"，下方列表框输出全部满足密钥 |

输入非法（如二进制串混入 2）会弹窗提示，不会崩溃。

## 5. TCP 传输演示

第一步，先启动服务端（它监听 `127.0.0.1:8888` 并等待连接）：

```bash
SdesServer.exe
```

第二步，另开一个终端启动客户端：

```bash
SdesClient.exe
```

客户端中输入 10bit 密钥与明文（支持中文），程序本地加密后经 TCP 发送"密钥 + 十六进制密文"两行报文；服务端解密并在其窗口打印结果，同时回传 `OK: 明文`。两端输出即为验收演示素材（见测试报告第3关截图）。

## 6. 如何验证程序正确（三步速查）

1. **对教材算例**：菜单 [1]，明文 `10010111` + 密钥 `1010000010`，应输出密文 `00111000`、K1=`10100100`、K2=`01000011`（与教材/GeeksforGeeks 标准算例一致）；
2. **跑交叉测试**：菜单 [2]，10 组样本应全部"通过"；
3. **暴力破解闭环**：菜单 [4]，用上述明密文对破解，结果列表中应包含原密钥 `1010000010`。

完整测试记录见 [测试报告](测试报告.md)。

## 7. 常见问题

| 问题 | 原因与解决 |
|---|---|
| 中文在控制台乱码 | 程序已自动启用 UTF-8 代码页；若仍乱码，请把终端字体设为支持中文的字体（如新宋体/Consolas+雅黑回退） |
| 服务端提示"端口 8888 绑定失败" | 上一个服务端实例未退出；结束多余的 `sdes_server.exe` 进程后重试 |
| 解密得到空结果 | 密文必须是长度为偶数的十六进制串（0-9/A-F/a-f），请检查是否复制完整 |
| 暴力破解找到多个密钥 | 这是正常现象（S-DES 明密文对不能唯一确定密钥），详见测试报告第5关分析 |
| GUI 窗口字体偏小 | 标准 Win32 默认字体，可在系统显示缩放中调整，不影响功能 |
